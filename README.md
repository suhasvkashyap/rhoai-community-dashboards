# OpenShift AI Community Dashboards

Community-contributed dashboards as code for Red Hat OpenShift AI, including Perses YAML and Grafana JSON for inference, training, evaluation, GPU monitoring, and agent observability.

## Purpose

Share reusable dashboards from field teams, customers, and the community. Keep customizations in Git and deploy them through GitOps, including in disconnected environments.

## Contributing

Submit a pull request with your dashboard and a short README covering:

- Purpose and intended audience
- Dashboard format and installation instructions
- Required data sources and metrics
- Tested OpenShift AI and component versions
- Maintainer or owner

Remove customer identifiers, credentials, and sensitive data before contributing.

## Support

Dashboards in this repository are community contributions, not Red Hat supported product content. Validate compatibility, queries, and data access controls before deploying them in your environment.
